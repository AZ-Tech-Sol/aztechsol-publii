The mark

Logo

The power button — a flat blue ring on a near-black face with the amber charge glyph — plus the AZTECHSOL wordmark: AZ/SOL set in Oxanium Regular 400 (Primary Blue), TECH in Rajdhani Bold 700 (logo amber) — a deliberate two-family mix, caps-normalized. The wordmark mirrors the name as spoken — az-TECH-sol. The mark never changes — amber glyph, always. Only the letters adapt: on dark (the website, the primary), blue AZ/SOL + amber TECH; on light (invoices, documents, print), ink AZ/SOL + amber TECH. One mark at every size — no small-size variant needed.

Type

Typography

Wordmark: Oxanium 400 (AZ/SOL) + Rajdhani 700 (TECH), a caps-normalized two-family mix — logo outlines only, never UI faces. Headings: Exo 2 (700–800), geometric techy sans. Body: Inter / system sans. Mono: system mono for code & specs.

Voice

Brand voice

  • Enterprise-grade but approachable — a partner, not a vendor.
  • Technical depth without jargon in client-facing materials.
  • Energy / “power” motif — you’re the current behind their AI and automation.
  • Bilingual capability is a differentiator, not a footnote.
